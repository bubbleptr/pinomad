# Remix Icon 图标的来源与许可证

官网首页的示意图（`apps/site/src/landing/diagrams.tsx`，`durable.tsx` 也用它）内联了几个 [Remix Icon](https://remixicon.com) 线性图标的路径数据：terminal-line、terminal-box-line、git-repository-line、key-2-line、lock-2-line、server-line、sparkling-2-line、user-3-line、checkbox-circle-line、close-circle-line、loader-4-line、flashlight-line、restart-line、flag-2-line。

- 来源：npm 包 `remixicon` 4.9.1（`icons/` 下的 SVG），路径原样复制，只在页面里改颜色和尺寸
- 许可：Remix Icon License v1.0。允许在网站和产品里免费使用、修改，不要求署名；禁止把图标本身单独出售或做成竞品图标库，禁止用作 logo 或品牌标识。全文见 <https://github.com/Remix-Design/RemixIcon/blob/master/License>
