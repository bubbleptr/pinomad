title: Docs and a blog on pinomad.si
description: Usage docs move from the repository to the site, and release notes get a home.
date: 2026-10-25
---

The usage docs that lived in the repository's `docs/` folder now have a home on
[pinomad.si/docs](/docs/), with search, a sidebar, and a Chinese edition under `/zh/`.
Release notes live in the [changelog](/changelog/); design write-ups will go here on the blog.

The web app stays where it is, at [app.pinomad.si](https://app.pinomad.si/).
