---
title: 用官方服务端
description: 登录 app.pinomad.si，把宿主加入账号，连上 Mac App 和 iPhone，打开推送通知。
---

官方服务端 `https://app.pinomad.si` 让你的设备在任何地方都能找到并连上宿主，不用自己架服务端。它替你的设备担保，设备直连不上宿主时转发密文；对话在设备和宿主之间端到端加密。

你需要一个服务端上的账号。注册要邀请码：先拿到一个邀请码，再用它建账号。

## 1. 注册或登录

注册：打开 [app.pinomad.si](https://app.pinomad.si/)（或 Mac App 的登录表单），点 **Create an account**，填邀请码、用户名和密码：

- 用户名只能用小写字母、数字和 `. _ -`，2–32 位。
- 密码至少 12 位。
- 邀请码只能用一次，7 天后过期；用过或过期了，找人再要一个。

账号建好就直接登录了。以后登录：

- **Web**：打开 [app.pinomad.si](https://app.pinomad.si/)，填用户名和密码登录。
- **Mac App**：还没连过宿主时，首页就是登录表单；否则点侧栏底部的 **Sign in**。**Server** 一栏已经填好 `https://app.pinomad.si`，只要填用户名和密码。

Server 一栏可以改。自己架了服务端的话，填它的地址（见[远程访问](/zh/docs/remote-access/)）。

## 2. 宿主加入账号

宿主需要 Node 25+，支持 macOS 和 Linux。登录后点 **Add a host**，会给出一条一次性命令，在要跑 agent 的机器上运行：

```sh
npm i -g pinomad && pinomad join https://app.pinomad.si <token>
```

命令只能用一次，10 分钟后过期；过期了点 **New command** 重新生成。`pinomad join` 把宿主登记到你的账号、记下服务端地址，并把宿主装成当前用户的服务，开机自启。加上 `--name "Mac mini"` 可以设定设备上显示的名字。同一台机器重复运行没有问题。

点 **Done**，宿主就出现在列表里。

## 3. 连上宿主

在宿主旁边点 **Pair**。服务端向宿主要一份一次性邀请，客户端用它完成配对，不需要扫码。配对过的宿主显示 **Connect**。

然后在 Settings → Providers 里接入模型，和[快速上手](/zh/docs/)一样。

## 4. iPhone

在 iPhone App 的 Settings 里点 **Sign in**，服务端已经填好 `https://app.pinomad.si`，填同一个用户名和密码登录。App 里还不能注册，先在 Web 或 Mac App 上注册。登录后账号下的宿主会列出来，在想用手机连的宿主上点 **Pair**。iPhone App 目前只在内部 TestFlight 上。

## 推送通知

对话等你回答、完成或失败时，iPhone App 可以推送通知。推送需要：

- 宿主已经用 `pinomad join` 加入账号；
- iPhone 登录的是和宿主**同一个账号**；
- App 里给这台宿主打开了推送（默认关闭，每台宿主单独设置）。

推送只带对话标题和事件，不带问题或回复；标题会经过服务端和 Apple。细节见[使用说明](/zh/docs/usage/)。

## 密码

改密码：在 Web 或 Mac App 上登录，在账号面板里点 **Change password**，填当前密码和新密码（至少 12 位）。当前设备保持登录，其他设备会被退出，用新密码重新登录即可；iPhone 重新登录后推送也会恢复。

忘了密码：服务端不存邮箱，没有找回邮件。找服务端的管理员（给你邀请码的人）重置，对方会给你一个新密码；用它登录后，再改成只有你自己知道的密码。

## 删除账号

删除账号：在 Web 或 Mac App 上登录，点账号面板最下面的 **Delete account**，再填一次密码。服务端删掉账号和它的登录会话、宿主绑定、推送登记，所有设备都会被退出。管理员账号不能删。

加入这个账号的宿主会立刻和服务端断开；要再经服务端连它，在宿主上用另一个账号重新 `pinomad join`。设备在各台宿主上的登记还在，因为这份名单由宿主自己保存：能直连宿主的设备（同一网络或 Tailscale）照常能连。要移除某台设备，到宿主的 Settings → Devices 里吊销它。
