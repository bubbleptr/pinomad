---
title: What the agent can do
description: Tools, projects and worktrees, subagents, named agents, codemode, MCP, and more.
---

The agent has pi's four tools (read, bash, edit, write) plus:

| Feature | What it does |
|---|---|
| Projects and worktrees | Register a directory as a project. In a Git repo each conversation works in its own worktree and branch, so your checkout stays untouched |
| Terminals | Open shells in the conversation's checkout from the Terminal page of the Web/desktop side panel. A family shares its terminals; they keep running while you are away and replay when you come back, but end when the host stops |
| Background processes | Long-running commands the agent starts, such as a dev server or a log monitor, tracked by the host; see their output or stop them in Tasks in the side panel (on the iPhone, in Overview), and a process that exits on its own reports back to the conversation. See [Background processes](/docs/background-processes/) |
| Forks | Branch off from a message into its own conversation, listed after its parent in the sidebar and opened in the main column; both lines keep going |
| Subagents | Hand self-contained tasks to subagents that run in parallel |
| Named agents | Reusable roles in `<data dir>/agents/<name>.md` — a `subagent` call or an `@name` mention delegates to one, optionally pinning its model and thinking level |
| Questions, not approvals | Tools run without approval prompts; when the direction is unclear, the agent asks 1–4 multiple-choice questions |
| codemode | The model writes JavaScript that calls other tools in a QuickJS sandbox; only the script's output enters the context |
| MCP | Servers configured in `~/.agents/mcp.json`, in the usual `mcpServers` format |
| Images | Paste, drop, or pick up to 4 images per message in the Web/desktop composer — resized to JPEG before sending |
| File attachments | Attach up to 10 files per message in the Web/desktop composer, each up to 10 MiB. They upload to the host as you attach them; the model gets read-only paths and copies a file into the working directory before changing it |
| Slash commands | Type `/` at the start of a message to run a command the host declares. The built-in `/compact [instructions]` summarizes older context; commands run on the host and are not sent to the model |
| Message times and delivery states | Message details and actions appear on hover or keyboard focus, and stay visible on touch. Your latest message has a double-check delivered mark; a send in progress shows Sending, an unanswered one Not confirmed, and a refused one Failed with the reason. Unconfirmed and failed sends can be retried, and failed ones edited |
| AGENTS.md and skills | Reads `AGENTS.md` / `CLAUDE.md` and skills from `~/.agents` and the project, on every request; a `$name` mention sends that skill's full text with the message |

Details and the MCP config reference: [Usage](/zh/docs/usage/) (Chinese).
