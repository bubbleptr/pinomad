---
title: 后台进程
description: agent 启动的 dev server 与监控命令，由宿主跟踪，在 Tasks 里查看输出或停止。
---

后台进程是 agent 在对话的执行检出里启动、由宿主跟踪的长期命令，比如 dev server 或日志监控。它不是供你交互输入的终端，也不是有独立对话的 Background 子代理。

## 在哪看

Web 和桌面端打开聊天区右侧面板的 **Tasks**，后台进程列在 **Processes** 分组里，和 Foreground 子代理并列。每一行显示名称（默认是命令首行）、状态点和运行时长，已结束的显示退出码、`Stopped`、`Failed` 或 `Lost`。点开一行可以查看只读输出，或点右上角的 **Stop** 停止它。

**Tasks** 面板首行的计数包含运行中的后台进程（如 `1 process running`）。**Tasks** 面板没打开时，聊天区头部 **Tasks** 图标上的活动点也会把运行中的后台进程算进去。

iPhone 上点对话标题栏的 **Overview**，在 **Processes** 一节里查看列表并点 **Stop** 停止（iPhone 上不显示进程输出）。

## agent 怎么用

宿主提供四个工具（Foreground 子代理不挂载这组工具）：

- `process_start`：在当前对话的执行检出里启动命令，返回进程 `id`。
- `process_output`：按位置增量读取输出（单次最多 16 KiB，已去掉 ANSI 转义序列）以及当前状态。
- `process_stop`：停止进程，等它退出后返回最终状态。
- `process_list`：列出当前对话家族里运行中和最近结束的进程，上下文压缩后靠它找回 `id`。

后台进程归属发起它的那条对话，列表和上限按根对话家族共享：同一个家族最多同时有 8 个未结束的进程（`Starting`、`Running`），已结束的保留最近 20 条。

进程自己退出时，宿主会把退出码（或信号）和最后几行输出（最多 40 行、4 KiB）发回发起它的对话。对话空闲时，这条回报会直接让 agent 接着干活；对话正在运行时，回报会排进当前运行。被你或 agent 停止的进程不会回报。

## 写监控命令（monitor）

宿主不支持"每匹配一行回报一次"，监控命令要写成**事件发生就退出**的单次命令，靠进程退出时的自动回报唤醒 agent。

在 Linux 上可以用 `tail` 配合 `grep`：

```sh
tail -n0 -F app.log | grep -m1 --line-buffered ERROR
```

- `-n0`：从当前文件末尾开始读，不被已有的旧行触发。
- `-F`：按文件名跟随，日志轮转或重建后继续读新文件。
- `-m1` 与 `--line-buffered`：匹配到第一行 `ERROR` 就立刻输出并退出，整条管道随之结束，宿主把这一行发回对话。

上面的写法依赖 GNU `tail` 在 `grep` 退出后及时结束，已在 Linux 上确认可用；macOS 自带的 BSD `tail` 在 `grep` 退出后能不能及时结束还没实测过，不要在 macOS 宿主上依赖它自动退出。

## 什么时候会停

后台进程在下面这些情况下会停止：

- **点 Stop**：你在界面上点 **Stop**，或 agent 调用 `process_stop`。宿主先向整个进程组发 `SIGTERM`，5 秒后还没退出就发 `SIGKILL`。
- **归档对话**：归档发起该进程的对话（或它所在的根对话、Fork）时，宿主先停止范围内的后台进程，等退出后再清理检出。
- **宿主正常关闭或重启**：宿主退出前会停掉所有运行中的后台进程，详情里显示 `Stopped when the host shut down`。
- **立即升级**：选择 **Upgrade now** 或执行 `pinomad upgrade --force` 时，宿主会在安装前停掉后台进程；选择 **Upgrade when idle** 则会等后台进程结束再升级。

如果宿主意外退出，下次启动时原先还在跑的条目状态会显示 **Lost**（详情显示 `Lost track after a host restart; it may still be running (pid …)`）。这表示宿主已经不再跟踪它，进程可能还在跑，需要你按显示的 `pid` 自己到宿主上处理。

输出只保存在宿主内存里（单个进程保留最近 512 KiB，全宿主已结束进程合计上限 64 MiB）。进程掉出 20 条历史、对话归档或宿主重启后，输出就看不到了。

## 限制

- **不能往进程里输入**：后台进程不接受标准输入；需要交互式操作时用右侧面板的 **Terminal**。
- **界面上不能重启**：已结束的进程在界面上没有重启按钮，需要再跑一次时让 agent 重新启动。
- **远程访问不转发端口**：远程访问宿主时，进程在宿主本机监听的 `localhost` 端口在客户端设备上打不开，端口转发会在后续版本支持。
