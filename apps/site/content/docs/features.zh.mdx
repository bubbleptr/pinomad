---
title: agent 能做什么
description: 工具、项目和 worktree、子代理、具名 Agent、codemode、MCP 等。
---

工具和 pi 一样是 read、bash、edit、write 四个，另外还有：

| 功能 | 说明 |
|---|---|
| 项目和 worktree | 把一个目录登记成项目。Git 仓库里每个对话在自己的 worktree 和分支上干活，你的检出不会被动到 |
| 终端 | 在 Web / 桌面端右侧面板的 Terminal 页里开 shell，工作目录是对话的检出。同一家族的对话共用一组终端；离开后终端继续运行，回来时接着回放，宿主停止时结束 |
| 后台进程 | agent 启动的 dev server、日志监控等长期命令，由宿主跟踪，在右侧 Tasks 里查看输出或停止（iPhone 上在 Overview 里查看和停止），自己退出时回报对话。见[后台进程](/zh/docs/background-processes/) |
| Fork | 从某条消息分出去，成为左侧列在父对话后面的独立对话，在主区打开；两条线各自往下聊 |
| 子代理 | 把自成一体的任务交给有名字的子代理：等它回答，或让它在后台干活、答完再告诉父对话；之后 agent 还能接着给它发消息，你可以在 Tasks 里查看和停止它 |
| 具名 Agent | `<数据目录>/agents/<名字>.md` 里的可复用角色——`subagent` 调用或 `@名字` 提及可以派给它，可选锁定模型和思考等级 |
| 提问代替审批 | 工具执行前不弹审批；方向拿不准时，agent 会提 1–4 个选择题 |
| codemode | 模型写一段 JavaScript，在 QuickJS 沙箱里调用其他工具，只有脚本的输出进入上下文 |
| MCP | 在 `~/.agents/mcp.json` 里配置 server，格式就是常见的 `mcpServers` |
| 图片 | Web / 桌面端输入框可粘贴、拖入、从 "+" 菜单选图，一条最多 4 张，发送前缩放并转成 JPEG |
| 文件附件 | Web / 桌面端输入框一条消息最多附 10 个文件，单个解码后最多 10 MiB。选中后立刻上传到宿主；模型看到的是只读路径，要改先复制到工作目录 |
| 斜杠命令 | 消息开头输入 `/` 执行宿主声明的命令。内置的 `/compact [说明]` 用来压缩较早的上下文；命令在宿主上执行，不发给模型 |
| 消息时间和送达状态 | 消息详情和操作在悬浮或键盘聚焦时显示，触屏上保持可见。最新一条送达后显示双勾；发送中显示 Sending，没确认显示 Not confirmed，被拒绝显示 Failed 和原因。未确认和失败的消息可以重试，失败的还可以取回输入框修改 |
| AGENTS.md 和 skills | 每次请求都会读 `~/.agents` 和项目里的 `AGENTS.md` / `CLAUDE.md` 与 skills；消息里用 `$名字` 提及的 skill 会把全文随消息发给模型 |

细节和 MCP 配置说明见[使用说明](/zh/docs/usage/)。
