---
title: 快速上手
description: 注册账号，一条命令把宿主加进来，在其他设备上登录，打开推送。
---

用 PiNomad 只要明白两件事：**宿主**（跑 agent 的那台机器）加入你的账号，**设备**登录这个账号。剩下的交给官方服务端 `https://app.pinomad.si`：设备在任何地方都能找到并连上宿主，对话在设备和宿主之间端到端加密；设备直连不上宿主时，服务端只转发密文。

不想用账号（只在一台机器上用、只走局域网或 tailnet、或者用自己架的服务端），见[不用账号](/zh/docs/without-account/)。

## 1. 注册账号

注册要邀请码。打开 [app.pinomad.si](https://app.pinomad.si/)（或 Mac App 的登录表单），点 **Create an account**，填邀请码、用户名和密码。账号建好就直接登录了。用户名规则等细节见[账号](/zh/docs/official-server/)。

## 2. 加入宿主

在要跑 agent 的机器（macOS 或 Linux）上运行：

```sh
curl -fsSL https://pinomad.si/install.sh | sh
~/.local/bin/pinomad up
```

第一行装好 pinomad，它自带 Node。`pinomad up` 接着问其他设备怎么连这台宿主，直接回车就是经官方服务端。它会打印一个要打开的网页和一个短码（形如 `WDJB-MJHT`），能开浏览器时会自动打开这个网页：

1. 在网页上登录账号，输入短码。Web 和 Mac App 里的 **Add a host** 也有同样的输入框。
2. 核对页面上显示的名字和系统，只在确实是你自己在那台机器上发起的时候确认。
3. 回到终端，`pinomad up` 把宿主加入账号，并装成开机自启的服务。

以后再加一台宿主，在那台机器上跑同样两行。

脚本把 Node 和 pinomad 装进 `~/.pinomad/runtime`，`pinomad` 命令放在 `~/.local/bin`。这个目录不在 PATH 里时（新 Mac 上就不在），脚本会打印要加进 shell 配置文件的那一行；加之前先用完整路径 `~/.local/bin/pinomad`。支持 Apple 芯片的 Mac 和 x64、arm64 的 Linux（glibc）。其他平台，或者想用自己装的 Node 25+，先 `npm i -g pinomad`，再 `pinomad up`。已经用 npm 装过 pinomad 的，脚本不会动它，也不会建 `~/.local/bin/pinomad`；先 `pinomad upgrade`，再 `pinomad up`。

## 3. 在其他设备上登录

用同一个用户名和密码登录，设备就会自动配对账号下所有在线的宿主，不需要扫码。

- **Web**：任何现代浏览器打开 [app.pinomad.si](https://app.pinomad.si/)。
- **Mac App**（Apple 芯片）：[GitHub Releases](https://github.com/bubbleptr/pinomad/releases) 上签名过的 DMG，会自动更新。
- **iPhone**：在 Settings 里点 **Sign in**。App 里还不能注册，先在 Web 或 Mac App 上注册。iPhone App 目前只在内部 TestFlight 上。

配对过的宿主显示 **Connect**。没有自动配上的宿主显示 **Pair**（比如以前在这台设备上删掉过的），点它配对。

然后在 Settings → Providers 里接入模型：用已经在付费的订阅登录（Claude、ChatGPT、Copilot 等）、填 API key，或者填你自己的 OpenAI / Anthropic 兼容 endpoint。

## 4. 推送通知

对话等你回答、完成或失败时，iPhone App 可以推送通知。在 App 的 Settings → Notifications 里打开（默认关闭，对所有宿主生效）；iPhone 登录的要是宿主加入的同一个账号。推送只带对话标题和事件，不带问题或回复；标题会经过服务端和 Apple。细节见[使用说明](/zh/docs/usage/)。

## 照看宿主

```sh
pinomad status      # 加入的账号、局域网端口、服务状态、宿主是否在线
pinomad upgrade     # 装上 pinomad@latest，等正在跑的任务结束后重启
```

`pinomad upgrade` 只升级 pinomad；再跑一次安装脚本会连它自带的 Node 一起更新。服务参数、日志和各平台的注意事项见[常驻运行](/zh/docs/service/)。

卸载：先 `pinomad service uninstall`，再删掉 `~/.pinomad/runtime` 和 `~/.local/bin/pinomad`。`~/.pinomad` 里其余的数据会留着，要删自己删。

## 客户端

| 客户端 | 获取方式 |
|---|---|
| Web | [app.pinomad.si](https://app.pinomad.si/)；宿主自己也提供（`pinomad link`） |
| macOS（Apple 芯片） | [GitHub Releases](https://github.com/bubbleptr/pinomad/releases) 上签名过的 DMG，会自动更新 |
| iOS | 目前只在 TestFlight 内部测试 |
| Linux、Windows | 用 Web 客户端 |
