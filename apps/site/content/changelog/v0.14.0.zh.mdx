**升级前**

- 用 `pinomad upgrade` 升级宿主。从 0.14.0 起，也可以在 Settings 里升级宿主。
- 具名子代理、后台进程、上下文拆分和在 Settings 里升级需要 0.14.0 的宿主。宿主是旧版时这些不显示，其余照常。

**在 App 里升级宿主**（Web、Mac App 和 iPhone）

- Settings → 宿主 → About 显示正在运行的版本，以及有没有新版本。**Upgrade…** 可以选 **Upgrade when idle** 或 **Upgrade now**，等待运行中的任务时可以取消。
- 安装失败时显示 npm 的输出。宿主没法自己升级时，会写明要在宿主上跑哪条命令。
- 可以选 **Off**、**Notify**（默认）或 **When idle**：选 When idle 时，宿主在没有任务运行时自己升级。

**子代理**

- 子代理有了名字，可以在后台运行，对话照常继续。后台子代理做完后向派出它的对话回报。
- 子代理可以在自己的 Git worktree 里、在新分支上工作，改动和你的分开。
- 子代理的对话是只读的。工作中的子代理可以停掉。要改它的任务，告诉派出它的对话。
- Web 和 Mac App 上，子代理列在 Tasks 里，按派出它的对话分组，正在工作的排在前面，不再出现在侧栏。
- iPhone 上，后台子代理显示在输入框上方的胶囊条里。

**后台进程**

- Agent 可以启动长时间运行的命令，比如开发服务器或 watcher，在它们运行时继续干活。
- Tasks（iPhone 上是 Overview）列出这些进程的状态和运行时长，可以停掉。Web 和 Mac App 上点开进程能看输出。
- 宿主重启时后台进程会停止。

**账号**

- 可以用邮箱和邮件验证码注册，忘记密码也用同样的方式重置。
- 可以用 Google、GitHub 或 Apple 登录，在账号的登录方式里关联或移除。这些选项只在开启了它们的服务端上出现。
- 只有用户名、没有邮箱的账号，在能发邮件的服务端上会被要求补一个邮箱。
- 去掉了邀请码。自建的服务端默认不开放注册，用 `pinomad server user add` 添加账号。

**Settings**（Web、Mac App 和 iPhone）

- Settings 按要改的东西分组：你的账号、这台设备、每台宿主的设置（Providers、Models、Agents、Chats、Devices、About）。
- 可以选浅色、深色或跟随系统。
- Hosts 合成一个列表。账号里这台设备还没配对的宿主排在已配对的后面，带 Pair。每台宿主有自己的页面，显示连接和能连到它的路线（Account relay、Tailnet、LAN、Internet）。
- 从账号移除的宿主，在你的其他标签页和设备上也会消失，不再一直重连。
- iPhone 上新增 Models、Agents 和 Chats 三页：选默认模型和思考等级，查看具名 Agent 和 MCP 服务器，设置排队消息的投递方式。

**对话**

- Usage 小节把上下文窗口拆成 System、Skills、Tools、MCP 和 Messages。
- 运行结束后 todo 列表随之消失，不再带着没勾掉的条目留在回答下面。iPhone 上点一下在原处展开。
- 进行中的条目是一个慢慢转动的虚线圈。
- 进行中的步骤闪光更平缓，计时按整秒走。
- 换到不支持当前思考等级的模型时，改用它支持的最低等级，不再一个都不选中。
- 保存自定义端点时，按端点自报或 Pi 的目录记下每个模型的思考等级。

**Web 和 Mac App**

- 主栏和侧面板是嵌在窗口里的圆角卡片。Settings 以页面形式取代侧栏打开，不再是对话框。
- 终端和对话背景一致。每个标签有自己的关闭按钮，Rename、Restart 和 Close 在标签的右键菜单里。
- 侧面板可以拉得更宽。
- 计时和变化中的数字不再随数字变化左右晃动。
