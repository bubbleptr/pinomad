**升级前注意**

- 推送现在只发给和宿主登录同一个账号的 iPhone。升级后在 iPhone 上登录宿主加入的那个账号（Settings → Sign in），并保持每台宿主的推送开着。只扫码配对、没登录账号的 iPhone 收不到推送了。
- 宿主和服务端要一起升级，旧客户端会提示需要更新。

**账号**

- 可以用邀请码注册：登录表单里点 **Create an account**，账号建好就直接登录。邀请码只能用一次，7 天过期。
- 服务端的管理员账号多了 **Invites**：生成邀请码、看谁用了、作废没用掉的。自部署的服务端不发邀请码，就没人能注册。
- 桌面端的登录表单默认填好官方服务端 `https://app.pinomad.si`，只要填用户名和密码；自部署的话可以改。

**多台机器**

- Web 和桌面端同时连着所有已配对的宿主，切换机器不再重连或刷新。
- 侧栏按机器分组，下面再分项目。草稿上的 Machine 选择器可以在另一台机器上开对话。
- 登录账号后，账号下的宿主会自动配对；在这台设备上移除过的不会。
- iOS 同时连着所有已配对的宿主。首页列出每台机器和它的对话、项目，草稿可以选机器，Settings 里每台机器有自己的页面。
- 跨机器的对话列表和搜索会标出每条对话在哪台机器上。

**对话**

- 点开对话立刻切过去，内容到之前显示骨架屏，Web、桌面端和 iOS 都是。打不开时会说明原因，不再一直转圈。
- 草稿的检出方式改成一个 **worktree** 勾选框：勾上新建 Git worktree，不勾就在项目目录里干活。

**模型服务**

- 自定义 endpoint 的模型改成可搜索的下拉框，列出 endpoint 提供的模型，勾选要用的，也可以手填 ID。
- 自定义 endpoint 的模型按 endpoint 报告的上下文长度、输出上限、推理和图片输入保存，不再套通用默认值。

**iOS**

- Settings 里每台宿主只列一次，最后是 **Add Host**；配对只剩 **Scan QR Code** 和 **Paste**。
- 重连超过一小会儿才在导航栏显示「Connecting…」，不再每次从后台回来都弹横幅。
- 发送草稿时输入卡片跟着键盘一起滑下去，不再闪一下。

**安全**

- 服务端和宿主提供的 Web 客户端都带上了 Content Security Policy 等安全响应头。
