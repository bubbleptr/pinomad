---
title: 排队的消息可以重排，Mac 设置不再开终端
version: v0.13.0
date: 2026-11-05
---

**升级前**

- 用 `pinomad upgrade` 升级宿主。重排排队的消息和加载更早的轮次需要 0.13.0 的宿主。宿主是旧版时不显示拖动手柄，对话照旧一次加载全部历史。

**排队的消息**（Web、Mac App 和 iPhone）

- 每条排队的消息是一张带拖动手柄的卡片，拖动它就能改变运行取用消息的顺序。iPhone 上长按手柄拖动，VoiceOver 提供 **Move up** 和 **Move down**。
- Edit 和 Withdraw 变成悬停时出现的图标按钮，窄屏上一直显示。steer 用箭头标记代替 "Steer" 标签，follow-up 不再带标签。
- 运行已经取走的消息不会再以 **Sending** 重新出现。
- 运行中完成的压缩不会再以 `<pi.compaction>` 出现在队列里。

**长对话**

- 对话打开时只加载最新的几轮，往上滚动时再加载更早的。
- 0.9.0 之前保存的自定义模型会补上端点报告的上下文窗口和输出上限，不会再按 128k 去压缩。自己设过的上限保持不变。
- 可以在 Moonshot、OpenRouter 和 Vercel AI Gateway 下使用 Kimi K3.1 Pro。

**Mac App**

- **Set up this Mac** 在后台装好并加入宿主，App 里显示进度，可以取消。不再打开终端，也不用输短码。
- Mac App 装的宿主以 PiNomad 的身份向 macOS 申请文件访问权限，不再是 "node"。

**Web 和 Mac App**

- 代码用 Geist Mono 显示。
- 设置去掉了标题行，打开时更大。手机上保留头部，用来放返回按钮。
- 右侧面板又能从左边缘拖动调宽了。
- 运行中打开概览时，改动和分支会马上显示，不用等运行结束。

**iPhone**

- 输入框下面的对话内容会被模糊，不再只是淡出。
- 工具步骤里实时的标签在流式输出时不再在几行之间来回滑动，被截断时也不再显示重影。
