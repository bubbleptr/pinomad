**模型选择器**（Web、Mac App 和 iPhone）

- Agent、模型和思考等级在一个地方选。Web 和 Mac App 上，输入框的胶囊按钮展开 Agent、Model、Thinking 三行，模型按提供方分组；iPhone 上，模型按钮在输入栏上方打开面板，里面是 Agent、模型和思考等级。
- 具名 Agent 钉住的项照常显示，但不能改（**Set by @name**）。Agent 钉的模型宿主没有提供时，它仍在列表里，但选不了。
- 切换模型时保留你选的思考等级：新模型没有这一档就用低一档里最近的，切回去时恢复。
- 两个提供方都有的同名模型，名字下面显示提供方。

**账号**

- 服务端发的邮件（注册、重置密码和确认用的验证码，以及安全通知）有了排版：验证码用大号字显示，可以整段复制，邮件跟随系统的深浅色。文案和主题没有变。
- Web 和 Mac App 上，邮件验证码在六个格子里输入，粘贴和验证码自动填充照常可用。
- 宿主从账号里移除后再次加入，会重新作为新宿主提示，Web、Mac App 和 iPhone 都是这样。
- 在同一个服务端上换另一个账号登录，不再丢掉前一个账号已配对的宿主。

**Tasks 和侧栏**（Web 和 Mac App）

- 侧栏有了关闭按钮，终端标签改成卡片样式。只有一类任务时，Tasks 不再显示分组标题。
- Tasks 会列出已结束的进程，Overview 不再把进程文档显示成原始数据。
- 新对话在开始之前不显示 Tasks、Changes 和 Terminal。

**iPhone**

- 输入栏改为一行三块：Add、圆形的模型按钮，以及里面带发送按钮的输入框。
- Overview 把子代理和后台进程列在同一个 **Tasks** 下。
