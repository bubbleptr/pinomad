**升级前注意**

- 宿主现在只读自己数据目录里的凭据，不再读 pi 的配置。升级后到 Settings → Providers 重新登录一次模型服务。
- 宿主和服务端要一起升级，旧客户端会提示需要更新。

**连接**

- 客户端先经中继连上，链路稳定后在后台切换到 WebRTC P2P 直连，不经过服务端转发；打洞失败就继续走中继。Web、桌面端和 iOS 都支持。
- 每台宿主可以单独选连接方式：Auto、Direct only（只走直连）、Relay only（只走中继）。
- 连接详情显示当前走的是 P2P 还是中继、两端是局域网、tailnet 还是公网地址，以及最近一次失败的原因。完整地址默认收起。
- 配对时宿主会给出多个地址（中继、局域网等），客户端按顺序尝试，一个连不上就换下一个。
- iOS 同时收集 IPv4 和 IPv6 候选，蜂窝网络下能走 IPv6 直连。

**消息**

- 你发的消息和回复都显示时间：今天的只显示时刻，更早的加日期，往年的再加年份。Web 和桌面端悬停可以看完整的日期时间。
- 你发的消息会显示是否送达宿主：发送中显示 Sending，30 秒没回音或断线时显示 Not confirmed，被拒绝显示 Failed 和原因，最新一条送达后显示 Delivered。Web、桌面端和 iOS 都支持。
- 没确认的消息在重连后会先向宿主核对，宿主确实没收到才重发，不会发重。失败的消息可以重试，也可以取回输入框修改。
- 回复用时改为算到回答的第一个字，只有一步的运行不再显示 0 秒。

**模型服务**

- Settings → Providers 列出全部模型服务：可以用订阅账号登录、填 API key，或添加自定义的兼容端点。Web、桌面端和 iOS 都能操作。
- 模型选择器里显示各厂商的 logo。

**图片**

- 宿主为图片生成缩略图和预览，对话里先加载小图，点开再看原图。

**iOS**

- 回复里的 TeX 公式会渲染出来，金额里的 `$` 保持原样。
- 草稿的项目和分支标签改成液态玻璃样式，运行结束后显示结果图标，上下文用量只显示圆环。
- 中日文旁边的引号恢复成对；提问卡片限高并可滚动；运行失败时显示服务商返回的状态和消息，原文放在详情里。
- 输入框的菜单会缩小以适应屏幕，不再把输入框顶走。
- 思维链抽屉里直播中的思考不再被限制在 4 行，并会一直滚到最新的文字。

**桌面端**

- 开发版和正式版使用各自的数据目录。
