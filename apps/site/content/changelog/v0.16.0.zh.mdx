---

**升级前**

- 在 Settings → 宿主 → About 里升级宿主，或者用 `pinomad upgrade`。插件需要 0.16.0 的宿主。

**插件**（Web 和 Mac App）

- 宿主从数据目录下的 `plugins/` 加载插件。插件可以加工具，在 Web 和 Mac App 上还能显示自己的侧栏面板和工具卡片；插件用模型写的 HTML 渲染的页面跑在沙箱里。iPhone 上插件的工具照样能用，但面板和卡片不显示。插件以宿主的权限运行，只装你信得过的代码。用法见[插件](/zh/docs/plugins/)，里面有一个示例插件，把模型写的页面显示在侧栏里。

**任务**（Web、Mac App 和 iPhone）

- Overview 里的 Subagents 改为 **Tasks**。每行用图标区分子代理和后台进程，用颜色和文字表示运行中、等回答、失败还是完成。
- 等回答的对话会显示 **Needs answer** 标签：Web 上在左侧栏，iPhone 上在对话列表里。

**错误提示**

- 错误显示在能改的地方：属于某个输入框的就显示在那个输入框上，属于整张表单的显示在按钮旁，一次性操作失败用 toast。同一操作再次失败会替换旧的 toast，重试时清掉。Web、Mac App 和 iPhone 都是这样。
- Web 上 MCP 服务出错、上传失败的原因直接显示在页面上，不用再悬停才看得到。

**Overview**（Web、Mac App 和 iPhone）

- 文件夹路径只显示上一级目录，worktree 对话显示的是项目所在的位置。没有改动时不再显示 Changes 行。
- Web 和 Mac App 上卡片更宽，worktree 的分支行带 **Worktree** 标签。

**Web 和 Mac App**

- 输入框恢复成浮起的样式，机器和项目选择器收在下方的托盘里；附件放在输入框里、文字上方。
- 确认过密码或验证码后，5 分钟内其他账号操作不再重复询问。已移除的设备不再出现在设备列表里。
- 确认对话框的取消按钮在左、操作按钮在右。在 About 里升级宿主改为弹出对话框。
- 提示气泡稍晚再出现；需要据此操作的信息直接显示在页面上，不再藏在提示气泡里。
- 对话框、菜单、主题切换、连接横幅、Send/Stop 和复制按钮的动效更顺滑。

**iPhone**

- 点通知直接打开对话，不再在主页等宿主连接。
- 确认宿主页面显示完整的 Host ID，可以和 `pinomad up` 打印的逐字核对。
- 动效和触感反馈打磨。
