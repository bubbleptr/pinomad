date: 2026-10-24
---

**输入框**

- Web、桌面端和 iOS 的输入框可以给消息附带本地文件，模型拿到的是只读路径。
- 宿主可以声明斜杠命令，在输入框里打 `/` 就能运行。
- 从 `$` 菜单选中的 skill，全文会随消息一起交给模型；只有选中的才展开。
- 排队中的消息在 agent 处理之前，可以插队、修改或撤回。
- `+` 合成一个菜单，放所有能塞进消息的东西；占位文字会提示 `@`、`$`、`/`。

**Agent**

- 对话进行到一半也能换具名 Agent：Web 端在模型选择器里换，iOS 在模型面板里换。

**Web 和桌面端**

- 侧栏底部改成用户栏，里面有宿主列表和设置。
- 运行详情从输入框挪进概览卡片，卡片分成可折叠的几节。
- 添加项目时分栏浏览文件夹。
- 消息里的图片滚到附近才加载，不再随对话一起传。

**iOS**

- 新的首页：状态卡片、按机器分组，另有项目页和筛选页。
- 每台机器有自己的设置页：宿主名、已配对设备、是否接受账号担保的设备。
- 点 ⓘ 按钮打开对话概览。
- 新的动效、触感反馈和 Lucide 图标；界面改成英文。

**宿主和服务端**

- 项目里的 skill 从当前目录一路找到 Git 根目录。
- 具名 Agent 的文件变化即使漏掉了监听事件也能恢复。
- macOS 上宿主的日志会轮转，不再无限增长。
- 苹果推送服务断开连接时，推送会重试。
