**升级前**

- 在 Settings → 宿主 → About 里升级宿主，或者用 `pinomad upgrade`。

**Web 和 Mac App**

- 换了新外观：文字和边框更柔和，圆角更小，深色表面偏冷，焦点环是蓝色。
- "连不上"、设备被吊销这类页面在矮窗口里能滚动，Unpair 和重新配对按钮不会被裁掉。

**上下文**（Web、Mac App 和 iPhone）

- Usage 小节改名为 **Context**。表盘换成按窗口比例排的方格，1M 窗口里的短对话也看得见，占了空间的每一部分至少有一格。
- 图例只显示每部分的 token 数，另加窗口里还剩多少（**Left**）。去掉了花费那一行。
- Web 和 Mac App 上，小节开头显示已用 token、窗口大小和占比，达到 80% 时高亮。
- AGENTS.md 等提示里的中日韩文字按更接近实际的成本计算，System 不再偏低、Messages 不再偏高。这一条需要 0.15.0 的宿主。
