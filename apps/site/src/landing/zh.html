崩溃重启也不丢进度的 coding agent

PiNomad 跑在你自己的机器上，直接调用本机的 shell 和代码。每一步模型和工具调用都会存下检查点，就算进程挂了或机器重启，也能从断处接着跑。Mac App、Web 和 iPhone App 连向同一个宿主，任务在哪都能随时接手。

多端接力

离开电脑也能接着管

在电脑前派好活，出门拿手机看进度，方向偏了随时插话调整。新设备扫一次性二维码就能完成配对，和宿主之间全程走端到端加密的安全通道。

  • 直连：局域网或 tailnet
  • 中继：只转发密文

断点续跑

步步存检查点，重启不用从头来

每完成一次模型调用或工具调用，Pi Durable 都会存下检查点。宿主重启后直接从最近一个检查点恢复，只有中断时没跑完的那一步需要重跑。

示意图：一条任务路线串联起多次模型调用和工具调用，每完成一步就插一面旗。宿主在两步中途崩溃，重启后直接从上一面旗恢复，只重做中断的那一步。

功能

agent 能做什么

除了和 pi 一样的 read、bash、edit、write 四个基础工具，还支持：

每个对话独立一个 worktree

在 Git 项目里，每个对话都在独立的 worktree 和分支上改代码，多个任务并行互不干扰，也不会动到你手头正在改的目录。

提问代替审批

调工具不弹确认框，不用一路点允许。遇到需要你拿主意的地方，agent 会列 1–4 道选择题让你拍板。

子代理和具名 Agent

独立的活可以拆给多个子代理并行去跑；也可以配置带专属提示词、模型和思考等级的具名 Agent，用 @名字 直接点名派活。

还有这些

Fork
从任意一条消息分出新对话，继承此前上下文，两条线各自往下聊。
codemode
模型写 JavaScript 在 QuickJS 沙箱里组合调用其他工具，只把最终输出放进上下文。
MCP
在 ~/.agents/mcp.json 里按通用的 mcpServers 格式配好就能用。
图片
Web 和桌面端输入框支持直接粘贴、拖入或选图，单条消息最多附带 4 张。
AGENTS.md 和 skills
每次请求都会读取 ~/.agents 和项目目录下的 AGENTS.md、CLAUDE.md 与 skills。

  • Linux、Windows

    直接使用 Web 客户端。

快速上手

三条命令跑起来

宿主需要 Node 25+，支持 macOS 和 Linux。

pinomad host 会直接复用你在 pi（~/.pi/agent）里配好的模型和认证。还没配过 pi？可以先跑 pinomad host --faux "hi"，用内置的模拟模型把界面点通试试。

项目还在早期，底层的 Pi Durable 也处于实验阶段；升级时请保持宿主和客户端的协议主版本号一致。

终端 
npm i -g pinomad
pinomad host   # 复用 pi 里配好的模型和认证
pinomad link   # 另开一个终端，打印 Web 客户端链接

派好活，放手让它跑。
