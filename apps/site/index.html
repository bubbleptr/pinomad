The durable coding agent for your own machine.

PiNomad runs on your machine, with that machine's shell and repos, and checkpoints every model and tool call. If the host crashes or restarts, the run picks up where it stopped. The Mac app, the web client, and the iPhone app all attach to the same runs.

  • Direct over your LAN or tailnet

Durable runs

Runs survive crashes and restarts

Pi Durable checkpoints every model call and tool call, so a restarted host picks up where it stopped instead of starting over.

A run drawn as a track of model and tool calls. Each finished call plants a flag. The host crashes between two calls; after the restart the run continues from the last flag, and only the half-finished call is redone.

Features

What the agent can do

The agent has pi's four tools (read, bash, edit, write), plus:

A worktree for every conversation

In a Git repo each conversation works in its own worktree and branch, so your checkout stays untouched.

Questions, not approvals

Tools run without approval prompts. When the direction is unclear, the agent asks one to four multiple-choice questions.

Subagents and named agents

Hand self-contained tasks to subagents that run in parallel, or delegate to a reusable role with an @name mention, optionally pinning its model and thinking level.

And also

Forks
Branch off from a message and keep both lines going.
codemode
The model writes JavaScript that calls other tools in a QuickJS sandbox; only the script's output enters the context.
MCP
Servers configured in ~/.agents/mcp.json, in the usual mcpServers format.
Images
Paste, drop, or pick up to 4 images per message in the web and desktop composer.
AGENTS.md and skills
Reads AGENTS.md / CLAUDE.md and skills from ~/.agents and the project, on every request.

Quick start

Up and running in three commands

The host needs Node 25+ on macOS or Linux.

pinomad host uses the models and credentials you set up in pi (~/.pi/agent). Haven't set up pi yet? pinomad host --faux "hi" runs a scripted fake model so you can click around.

Early and moving fast. Pi Durable is itself experimental, and the host and its clients must speak the same protocol major version.

Terminal 
npm i -g pinomad
pinomad host   # uses the models and credentials set up in pi
pinomad link   # in another terminal: prints a web client link

Start a run. Walk away.

Free and open source. It runs on your hardware, with your model credentials.
