AgentChatKit 是给 agent 对话用的 SwiftUI 组件库，支持 iOS 26+ 和 macOS 26+。审查前先读根目录的 `AGENTS.md`。改动违反下面这些约束时按 bug 报：

- `AgentChatCore` 不能依赖 SwiftUI、UIKit 或 AppKit；`AgentChatKit` 只依赖 `AgentChatCore`。
- trace 模型是本库自己的通用模型，不能引用 PiNomad 的类型或名字。
- 流式 Markdown：已闭合的块之后不能再变化；同一段文本不管怎么切分，结果都一样。
- 动效要尊重系统的“减弱动态效果”（`accessibilityReduceMotion`）。
- 界面文案要进 `Localizable.xcstrings`，带简体中文；不能有硬编码的英文字符串。
- 依赖锁精确版本，不能用范围。
- 测试只放在 `AGENTS.md` 列出的边界上；镜像字面量、映射或实现细节的测试按问题报。
